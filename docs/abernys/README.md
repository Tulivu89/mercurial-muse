# Abernys

Nov 15, 2026 · @AmbiProp

**Retired.** Abernys, the setting in this folder, isn't developed any more. Nothing here gets a session, a seed, a gold pass or engine work for its own sake, and plans shouldn't suggest it.

Bogwater, its module, stays the adventure's test module until a replacement comes, and both Abernys modules stay in `adventure/modules/` as test fixtures (the engine's tests and the converter's round trip run on them). Port Covenant isn't offered on the site.

The files stay for the record. The writing rules in `docs/praxis/bogwater-plan.md` still hold for every world.
